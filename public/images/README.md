# Images

Place your professional photo here.

Recommended filename: `photo.jpg` or `photo.webp`

Then update the photo placeholder in:
- src/pages/index.astro (About preview section)
- src/pages/about.astro (Two-column opening section)

Replace the `.photo-placeholder` div with:
```html
<img src="/images/photo.jpg" alt="Abdul Qayum Akindele" style="width:100%;border-radius:18px;object-fit:cover;" />
```
